# ImageViewingApp
This app allows you to search imgur's api wih any phrase you would like to see.
It will display the images in a 2 wide grid and allows you to select images to view in full screen.
Image pages are automatically requested as you scroll down the grid.

# Requirements
This app requires you to enter your own imgur client id before building. In the root of the project create a new property list file named "Secrets.plist". Enter a new key "API_CLIENT_ID" and enter your client id in this format "Client-ID {client_id}" as the value!
